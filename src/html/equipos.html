Rangos IP por cliente

Cada cliente administra sus propios rangos de IP. Un rango sin perfil se hereda a todos los perfiles del cliente; un rango con perfil aplica solo a ese perfil. Las IP estáticas fuera de rango se marcan como fuera de norma.
