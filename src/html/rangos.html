Rangos IP por cliente

Segmentos autorizados, auditoría y ajuste automático

Rangos IP

Cada cliente administra sus propios rangos; un rango sin perfil se hereda a todos los perfiles del cliente.

Ajuste automático de rangos

Compara las IP estáticas reales de cada cliente con los rangos ya establecidos. Solo propone crear rangos faltantes o ampliar los que se quedaron cortos para que el segmento quede en consecutivo; nunca elimina rangos ni toca los que están en conflicto.

Pulsa Analizar para calcular qué rangos faltan y cuáles hay que ampliar.

Resultado de la auditoría

Se revisa únicamente lo que está mal: rangos mal definidos, choques entre rangos, IP duplicadas, IP de un cliente dentro del rango de otro y equipos fuera de los rangos establecidos. Lo que solo falta configurar aparece aparte como cobertura.

Nuevo rango IP

Un rango debe vivir en un solo segmento /24 y no empalmarse con otro rango del mismo cliente.

Sin perfil = rango heredado para todos los perfiles.
Rango autorizado Aplica a las IP estáticas del cliente

Puedes escribir la IP completa (192.168.2.60) o solo el último octeto (60) indicando el segmento. Si dejas la IP final vacía, el rango será de una sola IP.

Sugerir IP libres del segmento

Calcula bloques consecutivos que no chocan con los rangos de ningún cliente ni con las IP ya registradas.

Elige cliente, segmento y cantidad de hosts; después pulsa «Sugerir».
